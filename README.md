# TN-Liste App v2

## Neue Funktionen
- Auswahl zwischen vier Word-Vorlagen:
  - Yaounde – 8:50 Uhr
  - Yaounde – 11:10 Uhr
  - Douala – 8:50 Uhr
  - Douala – 11:10 Uhr
- Ort vor Erstellung ändern
- Niveau vor Erstellung ändern
- Prüfungsnummer vor Erstellung ändern
- Datum ändern
- Farbe auswählen
- TN-Paare automatisch in die vorhandene Teilnehmer-Spalte einfügen
- Tabellenlayout und Kopf-Format der gewählten Vorlage bleiben erhalten
